# Academia Kuvona

A aplicação ativa está em **platform/**: loja de cursos, detalhes antes da compra, contas, sala de aula, instrutor e gestão.

Abre **abrir.bat** para iniciar em **http://localhost:3100** (Node.js 22+). O primeiro arranque instala as dependências e compila a aplicação. Mantém a janela aberta.

- [Instruções completas e funcionalidades](platform/README.md)
- [Estado, validação e passagem para Claude/Codex](platform/docs/STATUS.md)
- [Regras partilhadas dos agentes](AGENTS.md)
- [Publicação e configuração real](platform/docs/DEPLOY.md)

A plataforma funciona localmente com dados persistentes no servidor. A publicação, as carteiras comerciais reais, o email e a revisão das políticas exigem configuração própria; consulta o README da plataforma.

A demonstração antiga continua disponível em **abrir-demo-antiga.bat**, porta 8000. A sua documentação está em [README-DEMO.md](README-DEMO.md).
